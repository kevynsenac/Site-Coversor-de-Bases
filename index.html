DOCUMENTAÇÃO

Como funciona?

Todo número pode ser representado utilizando diferentes sistemas de numeração. O conversor interpreta o valor na base selecionada e gera sua representação equivalente nas outras bases.

01

Binário

Base 2

Utiliza apenas os dígitos 0 e 1. É amplamente utilizado em sistemas computacionais.

02

Octal

Base 8

Utiliza os dígitos de 0 a 7 e possui relação direta com grupos de três bits.

03

Decimal

Base 10

É o sistema numérico utilizado no cotidiano, utilizando os dígitos de 0 a 9.

04

Hexadecimal

Base 16

Utiliza os dígitos de 0 a 9 e as letras de A a F.

02
PROCESSAMENTO

Lógica da conversão

01
Entrada

O usuário informa o número e sua base.

02
Interpretação

O JavaScript interpreta cada dígito de acordo com a base selecionada.

03
Conversão

O valor é transformado em sua representação nas quatro bases.

04
Resultado

Os valores convertidos são exibidos individualmente na interface.

javascript 
valorDecimal.toString(2)
valorDecimal.toString(8)
valorDecimal.toString(10)
valorDecimal.toString(16)

O método toString() recebe a base desejada e retorna uma representação do número naquele sistema. Para hexadecimal, o resultado é convertido para letras maiúsculas.
